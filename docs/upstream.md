# Upstream components

Use these maintained projects as dependencies where appropriate. Links are references, not vendored code or claims that every Rover board has been tested with them.

| Function | Upstream |
| --- | --- |
| M5Stack board peripherals and display | [M5Unified](https://github.com/m5stack/M5Unified) |
| M5 DLight (BH1750) | [M5-DLight](https://github.com/m5stack/M5-DLight) and [M5Unit-LIGHT](https://github.com/m5stack/M5Unit-LIGHT) |
| M5 sensor-unit integration | [M5UnitUnified](https://github.com/m5stack/M5UnitUnified) |

Pin exact dependency versions in an application release. Check each upstream licence and hardware compatibility before use; this repository's MIT licence does not replace theirs.
