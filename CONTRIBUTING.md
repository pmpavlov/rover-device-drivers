# Contributing

Open an issue before adding a new device so we can check whether a maintained upstream driver already exists. A driver contribution should include a minimal example, a repeatable software check, its exact hardware revision and toolchain, units and error handling, and a short description of physical validation. Mark untested hardware support as unverified.

Do not submit private Rover application logic, credentials, device identifiers, raw recordings, private test logs, or copyrighted vendor material. Record the origin and licence of any third-party code. Prefer small changes and tagged releases over changing a published interface silently.
